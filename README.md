# 🅰️ TMP Font Toolkit · TMP 字体工具箱

> 🔤 Unity 编辑器插件：一键生成并优化 TMP 中文字体资产。
> 解决中文字体图集过大、生成流程繁琐、多平台压缩配置麻烦的问题。

**实测效果**：3500 字全量图集 **16MB → 0.6MB**（-96%），APK 整体 **-20%**

## 🚀 快速开始

```
1. 拷贝 TMPFontToolkit 文件夹到 Assets/
2. 菜单栏 Tools > TMP Font Toolkit 打开窗口
3. ① 选字符来源 → ② 选源字体 → ③ 勾平台 → ④ 选项 → ⑤ 一键生成
```

## 🖥️ 窗口使用详解

窗口从上到下分为 5 个区域，编号与操作顺序对应。

### ① 字符集（选择要烘焙哪些字）

三种来源模式，用顶部标签切换：

| 模式 | 适用场景 | 操作 |
|:---|:---|:---|
| **扫描场景+代码** | 推荐，自动收集项目实际用字 | 选扫描范围 → 点「开始扫描」→ 结果列表显示每个场景/脚本贡献的字数 → 可在「追加预留字」补充未来文案用字 |
| **字符文件** | 有现成的字库/文案文件 | 选择任意文本资产（.txt / .json / .csv），文件里的字符都会被烘焙 |
| **手动输入** | 只需要少量字 | 直接在文本框里输入字符 |

> 扫描范围可选：**当前场景**（只扫打开的）/ **所有场景+脚本**（扫 Assets/Scenes 和 Assets/Scripts 全部，含未打开场景）/ **自定义目录**（手动指定文件夹）
>
> 无论哪种模式，**ASCII（数字/字母/符号）和常用中文标点都会自动包含**，无需手动添加

### ② 烘焙参数（字体怎么生成）

| 参数 | 说明 |
|:---|:---|
| **源字体** | 要烘焙的 TTF/OTF 字体文件。内置了得意黑（SmileySans）可直接测试，也可换自己的字体 |
| **图集尺寸** | 字形图集的边长，见下方参数详解。字符越多选越大 |
| **采样点** | 字形渲染精度，决定最大清晰字号，见下方参数详解 |
| **Padding** | 字形间距，防边缘渗色，默认 9 即可 |
| **输出名称** | 留空自动用「源字体名_SDF」（如 SmileySans_SDF）|
| **输出目录** | 生成文件的存放位置，默认 `Assets/Art/Font`，可改 |

> 生成的文件会自动放入 **子目录**（以源字体名命名），多字体不会混乱

### ③ 平台压缩 + 体积预估（为发布渠道配置压缩）

- 勾选要发布的平台，**可多选**（PC / Android ASTC / Android ETC2 / iOS / WebGL）
- 每个平台行实时显示预估体积（单张 × 图集张数）
- 点「**评估容量**」用 TMP 真实打包测试当前字符集能否放入当前图集，返回实际图集张数与缺字情况；参数变更后需重新评估
- 同一图集可配置多套压缩，**打包时 Unity 自动按目标平台选用**，无需在 Build Settings 重复操作

### ④ 选项（生成后的附加操作）

| 选项 | 说明 |
|:---|:---|
| **设为 TMP 默认字体** | 生成后自动替换 TMP Settings 的默认字体（影响之后新建的 TMP 文本）|
| **配置 Fallback 兜底** | 把 LiberationSans 设为兜底字体，遇到字符集外的字自动用它显示，不会变方块 |

### ⑤ 操作按钮

| 按钮 | 说明 |
|:---|:---|
| **一键生成** | 完整流程：烘焙字形 → 导出图集 PNG → 设置勾选的平台压缩 → 按④选项收尾 |
| **设为默认字体** | 仅替换 TMP Settings 默认字体，不影响场景已有文本 |
| **替换场景所有 TMP 字体** | 把 Assets/Scenes 下所有场景（含未打开）中所有 TMP 文本组件替换为生成的字体，有确认弹窗 |

> 窗口底部为日志区，实时显示每个步骤的执行结果

## 🎛️ 参数说明

### 图集尺寸

| 尺寸 | 适合 | 说明 |
|:---:|:---|:---|
| 512 | 极少量字符 | 体积最小 |
| 1024 | <300 字 | 推荐默认 |
| 2048 / 4096 | 大量字符 | 常用 |
| 8192 | 超大字符集 | ⚠️ 慎用，老设备不支持 |

> 太小会拆成多张图集，太大浪费内存（体积 = 边长²）

### 采样点（Sampling Point Size）

最大清晰字号 ≈ **采样点 × 2**

| 采样 | 最大字号 | 用途 |
|:---:|:---:|:---|
| 32 | ~60px | HUD 小字 |
| 48 | ~96px | 常规 UI |
| 64 | ~128px | 大标题 |
| 90 | ~180px | 超大标题 |

> 💡 建议按用途分字体：标题用 90pt 小字集，正文用 48pt 大字集

### Padding

| 值 | 说明 |
|:---:|:---|
| 5 | 紧凑，小字号够用 |
| 9 | 标准推荐 |
| 14 | 保守，大字号/描边 |

### 平台压缩格式

| 格式 | 适用平台 | 每像素 | 说明 |
|:---:|:---|:---:|:---|
| DXT5 | PC / WebGL | 1 B | PC GPU 标准 |
| ASTC 6x6 | Android / iOS | 0.44 B | 体积小画质好，**推荐** |
| ETC2 | Android | 0.5 B | 全设备兼容 |

> 同一图集可同时勾选多平台，打包时自动选用对应格式
