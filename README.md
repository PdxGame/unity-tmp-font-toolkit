# 🅰️ TMP Font Toolkit · TMP 字体工具箱

> 🔤 Unity 编辑器插件：一键生成并优化 TMP 中文字体资产。
> 解决中文字体图集过大、生成流程繁琐、多平台压缩配置麻烦的问题。

**实测效果**：3500 字全量图集 **16MB → 0.6MB**（-96%），APK 整体 **-20%**

---

## ✨ 功能一览

| 功能 | 说明 |
|:---|:---|
| 🔍 字符集扫描 | 扫描场景 + C# 脚本，自动提取实际用字（毫秒级）|

## 🚀 快速开始

```
1. 拷贝 TMPFontToolkit 文件夹到 Assets/
2. 菜单 Tools > TMP Font Toolkit
3. ① 选字符来源 → ② 选源字体 → ③ 勾平台 → ⑤ 一键生成
```

## 🎛️ 参数说明

### 图集尺寸

| 尺寸 | 适合 | 说明 |
|:---:|:---|:---|
| 512 | 极少量字符 | 体积最小 |
| 1024 | <300 字 | 推荐默认 |
| 2048 / 4096 | 大量字符 | 常用 |
| 8192 | 超大字符集 | ⚠️ 慎用，老设备不支持 |

> 太小会拆成多张图集，太大浪费内存（体积 = 边长²）

### 采样点（Sampling Point Size）

最大清晰字号 ≈ **采样点 × 2**

| 采样 | 最大字号 | 用途 |
|:---:|:---:|:---|
| 32 | ~60px | HUD 小字 |
| 48 | ~96px | 常规 UI |
| 64 | ~128px | 大标题 |
| 90 | ~180px | 超大标题 |

> 💡 建议按用途分字体：标题用 90pt 小字集，正文用 48pt 大字集

### Padding

| 值 | 说明 |
|:---:|:---|
| 5 | 紧凑，小字号够用 |
| 9 | 标准推荐 |
| 14 | 保守，大字号/描边 |

### 平台压缩格式

| 格式 | 适用平台 | 每像素 | 说明 |
|:---:|:---|:---:|:---|
| DXT5 | PC / WebGL | 1 B | PC GPU 标准 |
| ASTC 6x6 | Android / iOS | 0.44 B | 体积小画质好，**推荐** |
| ETC2 | Android | 0.5 B | 全设备兼容 |

> 同一图集可同时勾选多平台，打包时自动选用对应格式

## 📝 字符集说明

- ASCII（数字/字母/符号）与常用中文标点**自动包含**
- 字符文件支持任意文本格式（.txt / .json / .csv）
- 推荐工作流：扫描实际用字 → 追加预留字；需要全量时用 3500 字表
